# 🚗 智驾伴侣（Smart Drive Companion）

## 项目简介
**智驾伴侣**是一个面向车主的智能车辆服务平台。项目采用微服务架构，根据用户购买的套餐（轻量版、标准版、豪华版）提供分级数据服务，包含车辆定位、告警分级、驾驶行为分析、碳排核算以及3D全息驾驶舱与AI语音助手等核心功能。

## 业务背景
随着车联网与新能源车的普及，车辆产生的数据量与日俱增。然而，现有的车主APP大多功能同质化，无法根据不同用户的付费意愿和实际需求提供差异化服务。本项目的业务背景是：构建一套能够支撑多租户（多版本）的智能车主平台，解决车主在车辆监控、故障预警、驾驶习惯改善以及碳排管理等方面的痛点。

## 目标用户
本项目面向**车主**（唯一的业务用户），按套餐分为三个层级：
- 🥉 **轻量版用户**：需要最基础的车辆定位和告警服务，能随时了解车辆状态。
- 🥈 **标准版用户**：需要深入分析驾驶行为、油耗统计和月度报告，追求数据化和专业度。
- 🥇 **豪华版用户**：追求极致的科技体验，需要3D全息车辆模型、3D城市地图、AI语音助手及碳排报告等高级功能。
