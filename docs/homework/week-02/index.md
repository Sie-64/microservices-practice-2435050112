# 第2周作业：项目选题

## 一、项目选题说明

### 1. 项目名称
**智驾伴侣——智能车主服务平台**

### 2. 要解决的实际问题和业务背景
随着车联网与新能源车的普及，车辆产生的数据量激增。然而，现有的车主APP大多功能同质化，缺乏差异化服务。本项目旨在构建一套能够支撑多租户（多版本）的智能车主平台，解决车主在车辆监控、故障预警、驾驶习惯改善以及碳排管理等方面的痛点。

### 3. 主要目标用户及其需求
本项目面向**车主**（唯一的业务用户），按套餐分为三个层级：
- **轻量版用户**：需要最基础的车辆定位和告警服务，能随时了解车辆状态。
- **标准版用户**：需要深入分析驾驶行为、油耗统计和月度报告，追求数据化和专业度。
- **豪华版用户**：追求极致的科技体验，需要3D全息车辆模型、3D城市地图、AI语音助手及碳排报告等高级功能。

### 4. 选择该题目的原因
该选题业务边界极其清晰，天然适合微服务拆分。车辆、告警、碳排、AI等领域可独立成服务，完美契合后续课程中JWT认证、网关鉴权、BFF聚合、消息队列、分布式事务、链路监控及Docker/K8s部署等核心知识点。

### 5. 项目的初步边界与后续演进
- **当前范围**：9大微服务模块（认证、车辆、告警、驾驶行为、碳排、预测、3D建模、AI助手、BFF），3套前端主屏与对应副屏。
- **暂不实现**：真实车辆硬件对接、复杂机器学习预测模型、电影级3D渲染。
- **演进方向**：按阶段逐步引入注册中心、网关、配置中心、认证授权、消息队列、分布式事务、链路追踪、Prometheus监控及Docker/K8s部署。
